# Consolidados S.A.S

Sitio web en React + Vite.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Assets

- `src/assets/cropped-image-modified-300x100.png` — logo (componente `Logo`)
- `public/favicon.svg` — favicon del navegador
- `public/icons.svg` — sprite de iconos (componente `Icon`)
